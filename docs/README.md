# Ybypy-a-

1. Tema do ProjetoO nome Yby Py'a vem do Tupi-Guarani e significa "Coração da Terra". O projeto consiste num website educativo e institucional focado na conscientização sobre reciclagem, sustentabilidade e preservação dos recursos naturais. O site aborda como o correto reaproveitamento de materiais recicláveis reduz a extração de matérias-primas virgens e atenua o impacto ambiental nos ecossistemas.

2. ObjetivosGeral: Desenvolver uma plataforma web acessível e intuitiva para promover a educação ambiental e incentivar práticas sustentáveis no quotidiano.Específicos:Divulgar dados e tabelas informativas sobre resíduos sólidos e reciclagem no Brasil.Mapear e indicar locais para descarte adequado de materiais recicláveis.Disponibilizar guias práticos de reciclagem, notícias atualizadas e curiosidades.Cumprir as diretrizes universais de acessibilidade (WCAG), garantindo legibilidade, alto contraste e navegação por teclado.Desenvolver uma interface totalmente responsiva adaptada a computadores, tablets e telemóveis.
